# Descarte Consciente

Projeto de extensão desenvolvido com foco na conscientização sobre o descarte correto de lixo eletrônico e seus impactos no meio ambiente.

---

## Sobre o projeto

O objetivo deste site é informar e conscientizar as pessoas sobre os riscos do descarte incorreto de resíduos eletrônicos, apresentando:

- O que é lixo eletrônico
- Seus impactos ambientais
- Como descartar corretamente
- Pontos de coleta
- Quiz interativo educativo

---

## Tecnologias utilizadas

- HTML5
- CSS3
- Font Awesome
- Google Fonts

---

## Objetivo acadêmico

Este projeto foi desenvolvido como atividade de extensão acadêmica, buscando unir tecnologia, design e conscientização ambiental.
